# Paraspect Storybook

A Next.js app-router project for personalized AI storybooks with auth, payments, and print/PDF delivery foundations.

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000/storybook`.

## Environment variables

Copy `.env.example` to `.env.local` and fill values.

## Supabase SQL

Run `supabase/stories.sql` in your Supabase SQL editor.
